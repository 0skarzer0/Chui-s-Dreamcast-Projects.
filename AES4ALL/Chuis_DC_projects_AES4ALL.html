FEATURES


Using MMU for loading large rom files. Two cache levels: free RAM and SRAM.
AES and MVS systems supported.
Close to fullspeed emulation (frameskip0 with sound-fx).
Fast FAME Motorola 68000 core by Fox68k.
Fast FAZE Zilog Z80 core by Fox68k.
Custom PowerVR2 graphic core (fast tile caching).
Autoframeskip for real speed.
Joystick is emulated with analog and digital pad + A,B,X,Y and Start/R-Trigger.
Complete menu with L-Trigger: region selector, frameskip control, graphic filtering, hardware reset...
Crystalline sound without lag.
Both control players emulated.
SD-Card support.
More info: Chui's DCEMU Forum.

CONVERTNEO TOOL


For playing AES4ALL (NEO4ALL/AES), you need convert typical ZIP-compressed NEOGEO roms, 'convertneo' command-line tool allows this conversion of supported games (GNGEO). This tool is incluyed on AES4ALL packages for Windows and GNU/Linux.
First, put all files of NEOGEO bios (uncompress neogeo.zip of MAME) and 'aes-bios.bin' file of NEOGEO home to bios directory. Then, go to Windows CMD and execute 'convertneo.exe' with filename of ZIP as parameter, for example:
C:\temp\convertneo> convertneo.exe migame.zip
If all are ok you will have a 'migame.aes' file for playing with AES4ALL. Test your .AES converted files first with AES4ALL for Windows or GNU/Linux.
Extra Parameters:
-usa USA region (default)
-jap Japan region
-eur European region
-asia Asia region
-home AES/home system (default)
-arcade MVS/arcade system
UPDATE: For new version you need rebuild your old .AES files and you can use old .AES files as source. Also now exists, and necessary for fast loading, a .PRF file when exists prefetch.


BURNING INSTRUCTIONS


For Dingoo, copy all files and directories at same directory of your SD card and run 'aes4all.dge' binary.
You will find instructions on how to use Selfboot inducer to make a bootable disk for the Dreamcast HERE.
You must include all files of directory 'dreamcast' of binary package.
For running with SD-Card, copy all files (include neo4all directory) to root of SD.
For building a stand-alone bootable:

1- Copy your selected game (AES/PRF files) to a directory, rename it as game.aes/game.prf and add 1st_read.bin, config.cfg and splash.bmp (edit it for customizing).

2- Toast it using your bootable method.
